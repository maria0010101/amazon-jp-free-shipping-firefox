# 附加元件說明

在 Amazon 日本商品卡片標示免運文字（含條件式免運），支援桌面與 Android Firefox。不隱藏其他商品，不蒐集或傳送個人資料。實際免運資格與配送範圍請以 Amazon 配送地址及結帳畫面為準。
